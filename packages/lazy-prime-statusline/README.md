# lazy-prime-statusline

Lazy Prime's in-process status line for pi / prime-agent: `π · model ◕ xhigh · ~/path · ⑂ branch *2 +1 ?3 · ◫ 42% · $1.23`, with distinct segment colors and a right-aligned session name. Toggle it with `/lazy-prime`.

This package applies where the TUI runs in-process: **pi**, or **prime-agent through the Lazy Prime launcher**. It is part of [Lazy Prime](https://github.com/ephraimduncan/lazy-prime). MIT.
