# pi-omp-statusline

[oh-my-pi](https://github.com/can1357/oh-my-pi)'s status line, cloned for pi / prime-agent: `π · model ◕ xhigh · ~/path · ⑂ branch *2 +1 ?3 · ◫ 42% · $1.23` with omp's exact segment colors, session name right-aligned. Toggle with `/statusline`.

Footers are render functions, so this applies where the TUI runs in-process: **pi**, or **prime-agent via the `prime-omp` launcher**. Part of [pi-omp-tools](../../README.md). MIT.
